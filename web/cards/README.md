# 《冰她》卡图

13 张角色卡图，按 `card.key` 命名：

```text
alien.webp       外星人（伪装成人类）
infected.webp    感染者
culprit.webp     犯人（红色影子暗示身份）
accomplice.webp  从犯
president.webp   学生会长
monitor.webp     班长
honors.webp      优等生
discipline.webp  风纪委员
library.webp     图书委员
health.webp      保健委员
ojou.webp        大小姐
news.webp        新闻部
homebody.webp    归宅部
```

- 512×683 WebP；源图 768×1024。
- 角色均为成年女性，校服/常服，无血腥、暴露或性化构图。
- 生成参数/种子/提示词见 `manifest.json`；生成工具为 `img-gen/cardgen.py`。
- 卡面文字和规则数值仍由 UI 从服务端 view 渲染，不写死在图片里。
